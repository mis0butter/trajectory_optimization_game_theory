# Comments to the author

This paper proposed a framework for non-cooperative orbital
games by projecting continuous control problems into a
discrete set of candidate trajectories. Some comments are
as follows:

1. How to obtain the vertex position in the local orbital
frame?
2. It is not clear that how to use the Nash optimal
probability distribution $w^*$;
3. The MPC problem (6) cannot generate solution that the
tracking performace is perfect. So is the resulting mixed
strategy meaningful?
4. What is the distance between the method proposed in this
manuscript and the solution to the original problem?
Theoretical analysis is necessary.Reviewer 5 of CDC 2026 submission 2010
